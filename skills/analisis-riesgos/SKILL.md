name: analisis-riesgos
description: Preparar el modelo de amenazas de un sistema a partir de su arquitectura.
---

Cuando Vicente pida revisar la seguridad de un servicio, consulta los documentos que autorizó. Dibuja primero el recorrido de una operación concreta e identifica el dato, quién inicia la operación y qué componente cambia de nivel de confianza.

Usa la plantilla [references/template.md](references/template.md), conservando su estructura y completando en español solo lo respaldado por evidencia. Para cada amenaza registra componente, escenario, impacto, mitigación, responsable conocido y prueba de verificación. Marca como pendiente lo que requiera contexto adicional. Si se solicita guardar el resultado, prepara el contenido mediante las capacidades disponibles y comunica el estado de aprobación.
