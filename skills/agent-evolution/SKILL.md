# Evolución de agentes

Empieza por un fallo documentado o un objetivo medible. Localiza el agente, skill y ejemplos que intervienen; distingue la causa observada de una hipótesis. Propón un cambio acotado que mantenga la responsabilidad y los límites del agente.

Define una comprobación antes/después con la misma entrada y criterios, incluyendo una regresión relevante. No afirmes mejora sin resultados; registra impacto, contraejemplos y tareas no verificadas. Conserva el cambio como propuesta si modifica instrucciones compartidas o un perfil activo.

Usa evaluación formal cuando el cambio afecte comportamiento en varios casos; consulta `agent-evaluation` solo si está disponible y el encargo requiere esa comparación.
