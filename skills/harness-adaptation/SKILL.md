# Adaptación a un harness

Inspecciona la configuración de origen y la documentación o el entorno de destino que el usuario proporcionó. Mapea cada rol, skill, herramienta, delegación, permiso y efecto a su equivalente real. Mantén IDs y alcance cuando sean compatibles; documenta funciones sin equivalente como limitaciones, no como capacidades.

Prepara los archivos del formato de destino y conserva un manifiesto de correspondencias. Valida sintaxis, referencias y rutas con las capacidades disponibles. Si la adaptación solicita escribir en un entorno externo o instalar perfiles, presenta el resultado como propuesta hasta que exista autorización y el entorno permita la acción.

No añadas credenciales, herramientas, permisos, autoejecución ni datos de integración inferidos. No declares que un agente está activo por producir una definición portable.
